# 2026-11-05 11:25 EST: Release v0.2.0

## Summary

This is the first tagged release. 0.1.0 was built and installed locally on 2026-11-04 but never
tagged. Version 0.2.0 adds the features merged since then, so it is a minor bump.

## Changed

- `Cargo.toml` (`[workspace.package] version`) and `Cargo.lock`: 0.1.0 to 0.2.0 for
  `cargo-testcache` and `cargo-testcache-core`, made by `cargo release minor`.
- Included since 0.1.0:
  - per-target `inputs` and `spawns` (issue #3, PR #6);
  - `optional_inputs` (issue #4, PR #7);
  - clearer `--explain` wording, a warning for globs matching over 1,000 files, and a
    first-run tip (issue #5, PR #8);
  - the stat cache for executable digests, `hashes.json`, with `--no-stat-cache` and
    `CARGO_TESTCACHE_FULL_HASH` (issue #9, PRs #10 and #11).

## Tests

- None run for the version bump itself: `release.toml` sets `verify = false`, and CI runs the
  full suite on the release pull request and on the `v0.2.0` tag. The merged PRs listed above
  each passed `just fmt`, clippy with `-D warnings` and `just test`.

## Decisions

- `cargo-release` asked for confirmation interactively, so `scripts/release-prepare.sh`'s
  command was run directly with `--no-confirm`, after the script's checks passed (on `main`,
  clean, equal to `origin/main`).
