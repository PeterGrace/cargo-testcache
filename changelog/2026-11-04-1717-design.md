# Design: cargo-testcache

- Generated the repository from `PeterGrace/rust-template` with GitHub CI, Hegel, dylint,
  cargo-release and the claims ledger. There is no Dockerfile, because this is a CLI tool.
- Added the design, `docs/superpowers/specs/2026-11-04-cargo-testcache-design.md`. It describes
  a Cargo subcommand that skips a test binary when that binary and its declared runtime inputs
  match a recorded pass, in the way Go's test cache works. It covers the prior art (no Cargo
  tool does this yet), the cache key, the runner, the configuration, the command line, the
  limits of correctness, the architecture, the tests and the open questions.
- No code yet. The template's placeholder code is unchanged.
